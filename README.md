## 현재 수집 범위

API 키 없이 아래 한국어 공식 채널의 공개 RSS를 약 6시간마다 확인합니다. 명조는 제목에 **전투 모션**, 이환은 **캐릭터 쇼케이스**가 들어간 영상만 수집합니다. 각 게임 전용 공식 채널이므로 게임명이 제목에 없어도 제목 조건에 맞으면 포함합니다. 젠레스 존 제로는 제목에 **캐릭터 플레이**가 들어간 영상만 수집합니다. 한국어 영상이 먼저 표시됩니다.

- 젠레스 존 제로: https://www.youtube.com/@ZZZ_KO/videos — 캐릭터 플레이 (캐릭터 PV 제외)
- 이환: https://www.youtube.com/@NTE_KO/videos — 기존 캐릭터 쇼케이스 10개 (캐릭터 PV 제외)

## 사이트에서 채널과 수집 조건 변경

1. 오른쪽 위 **관리자 연결**을 누릅니다.
2. GitHub에서 이 저장소(action-reference)만 선택한 Fine-grained personal access token을 만듭니다. Contents 권한만 Read and write로 지정합니다. Actions 쓰기 권한은 필요하지 않습니다.
3. 토큰을 사이트의 관리자 연결 창에 입력합니다. 채팅에 보내거나 저장소 파일에 넣지 마세요.
4. **게임 · 채널 관리**에서 게임 이름, 채널 주소, 제목 조건을 입력하고 **저장하고 수집 시작**을 누릅니다. 기존 게임은 수정·삭제·수집 켜기/끄기도 가능합니다.

설정 파일을 따로 올릴 필요가 없습니다. 사이트가 GitHub Contents API로 config.json을 저장하면 해당 변경으로 Actions 수집·배포가 실행됩니다. 보통 1~3분 뒤 결과가 반영되며 진행 상태를 관리 창에서 확인할 수 있습니다. 새 채널은 최근 RSS 목록부터 수집합니다. 전체 과거 영상은 별도 초기 수집 작업이 필요합니다.

GitHub 토큰은 공개 코드·설정 파일·내보내기에 포함하지 않습니다. api.github.com으로만 전송하며 현재 탭의 sessionStorage에 보관하므로 탭을 닫거나 연결 해제 시 재연결이 필요합니다. 저장소를 수정할 권한이 없는 방문자는 설정을 변경할 수 없습니다. 연결 해제 후에도 이미 저장한 예약 수집은 계속 실행됩니다. 기존 로컬 설정을 공유 설정으로 옮기려면 연결 후 설정 가져오기를 이용할 수 있습니다.

공유 설정은 페이지를 열 때마다 갱신됩니다. 직접 추가한 영상은 현재 브라우저에만 저장됩니다. 설정 내보내기/가져오기는 백업용으로 유지합니다. 다른 곳에서 동시에 설정을 바꾸면 SHA 충돌을 감지하여 덮어쓰지 않으므로 다시 연결하여 최신 설정으로 수정하세요.

## RSS 범위와 중복

최초 한 번 공식 채널의 전체 동영상 탭·채널 내부 검색·공개 검색을 대조하고, 영상별 공식 채널 ID와 제목·게시일을 확인하여 data/archive.json에 초기 목록을 보관합니다. 검색 결과의 영어 번역 제목도 후보에 포함하고 한국어 원제를 다시 확인합니다. 이후에는 RSS의 최근 목록에서 신규 영상을 추가하며, 과거 영상은 기간 제한 없이 유지합니다. 전체 목록 재수집은 자동 실행하지 않습니다. 이전 배포 결과를 읽지 못하면 수집·배포를 중단하여 누적 내역을 보호합니다. RSS 범위를 넘어서는 빠른 업로드나 수집 중단 중 영상은 놓칠 수 있습니다.

동일 영상 ID는 한 번만 표시합니다. 한국어를 우선하며, 이번 실험은 한국어 채널만 수집합니다. RSS에는 길이·번역 제목이 없어 서로 다른 ID의 언어별 내용 중복은 자동으로 확정하지 않습니다. 기존 메타데이터 기반 중복 함수는 해당 정보가 제공된 경우에만 작동합니다.

## 자동화와 실패 처리

.github/workflows/pages.yml에서 Python 표준 라이브러리로 공개 RSS를 읽고 Node로 중복을 정리한 뒤 배포합니다. API 키나 GitHub Secrets 등록은 필요하지 않습니다. 전체 채널 수집 실패 시 배포를 중단하고 기존 사이트를 유지합니다. 일부 실패는 사이트에 표시하고 이전 수집 데이터를 가능한 범위에서 유지합니다. 예약 작업은 GitHub 사정에 따라 지연되거나 비활성화될 수 있으며 Actions에서 확인할 수 있습니다. 최신 확인 시간은 사이트에 표시됩니다.

RSS가 실패하면 동일 채널의 공개 `/videos` 탭에서 최근 15개를 확인합니다. 채널 ID와 선택된 동영상 탭을 검증하며 다른 추천·재생목록은 읽지 않습니다. 공개 시기가 상대 표시로만 제공되면 기간으로 보관하고 정확한 날짜를 만들어 넣지 않습니다. 신규 무브셋은 이 기간의 가장 이른 날짜가 캐릭터 출시 이후인 경우에만 추가합니다. 이미 확인된 영상의 정확한 게시일은 유지합니다. 같은 실행에서 공유 채널은 재사용하며 두 경로가 모두 실패하면 오류를 그대로 표시하고 기존 기록을 보존합니다.

채널이 공식인지 자동 인증하지 않으므로 등록 전 출처를 확인하세요. 사이트에 배포된 설정과 영상 목록은 공개됩니다. 외부 재생 제한 영상은 유튜브에서 열기를 이용하세요.

## 로컬 실행 및 검증

Python 3.12 이상과 Node 24 기준입니다. 예약 수집과 사이트 실행에는 추가 패키지가 필요하지 않습니다.

- 수집: node scripts/collect.mjs
- 테스트: python -m unittest discover -s scripts -p rss_test.py
- 중복 테스트: node --test scripts/dedupe.test.mjs
- 미리보기: python -m http.server 8000 → http://localhost:8000

## 기본 채널 출처

명조 한국어 채널은 개발사의 Google Play 안내에 링크되어 있습니다: https://play.google.com/store/apps/details?hl=ko&id=com.kurogame.wutheringwaves.global

최초 전체 목록 다시 만들기(필요할 때만): yt-dlp 설치 후 `python scripts/backfill.py --game wuthering-waves` 또는 `python scripts/backfill.py --game neverness-to-everness`. 영상 파일은 받지 않고 공개 메타데이터만 읽습니다. 예약 수집에는 yt-dlp 설치가 필요하지 않습니다.

젠레스 존 제로 최초 목록 재확인: `python scripts/backfill.py --game zenless-zone-zero`. 게임별 카테고리에 적재하며 기존 명조·이환 목록도 보존합니다.

저장소 연결 테스트: `node --test scripts/github-sync.test.mjs`. 실 토큰 없이 UTF-8 저장, 개인 영상 제외, SHA 충돌, 미연결 차단을 검증합니다.

## 캐릭터 무브셋 탭

화면은 오피셜 / 캐릭터 무브셋 탭으로 분리하고, 양쪽 모두 게임별 카테고리에 적재합니다. 캐릭터 무브셋은 ON Game(명조·젠존제), Drave-kun(젠존제), The Chaos Duck(이환)에 더해 누락 보완용 NaruVT(명조), GameGaki(이환)를 수집합니다. config.json의 creators에 채널별 제목 포함·제외 조건을 보관합니다. 유출·CBT·베타 표기와 캐릭터 합본은 제외합니다. 제목·설명 기반 제외이므로 숨겨진 사전 빌드 여부까지 보증하지는 않습니다.

누락 보고서는 공개 페이지에 표시하지 않습니다. 공개 배포물에는 영상 목록만 복사하며 내부 대조 파일을 포함하지 않습니다.

보완 채널은 BLACK DJ, Runa, YukyTsuki, Fluffintu, Ruby Inferno, KamiKazeyo137, Kiwi Zero, Aliya 등으로 확장했습니다. 과거 후보는 캐릭터·업로더·공개일·설명을 대조하며, 출시 전 테스트·유출·다인 합본·모드/팬 제작 후보는 추가하지 않습니다. 공개일을 정확히 확인하지 못한 과거 채널 목록은 게시 시기 범위의 가장 이른 날짜가 캐릭터 출시 이후인 경우에만 보완 목록에 넣었습니다. 퍼니싱 NieR 시연은 중국 서비스 정식 출시 이후 영상이며, 글로벌 출시일은 화면의 정렬 기준으로 유지합니다.

기본 공격이나 특정 기술만 확보한 영상은 `기본 공격 모션`, `개별 기술 모션`, `개별 모션`으로 구분하고 유형 필터에서도 선택할 수 있습니다. 개별 시연 제목만으로 모든 동작 포함 여부를 보증하지 않습니다. 개인 대조 보고서는 영상 미확보와 일부 모션만 확보를 따로 집계하며 공개 저장소 밖에서 생성합니다.

채널별 `approvedVideoIds`는 직접 확인한 과거 영상의 제목·게임명 선택 조건만 보완합니다. 유출·베타 제외 조건과 게임 출시일 제한은 계속 적용합니다. `excludedVideoIds`에 지정한 반복 영상은 RSS나 과거 목록에서 다시 유입되어도 제외합니다. 신규 자동 수집은 채널별 시연 제목 조건을 계속 사용하며, 과거 영상의 검토 범위·확인된 번역 제목은 RSS 갱신 시 유지합니다.

일본어 개별 모션 전문 시리즈도 수집합니다. Hugo HK의 モーションリファレンス, さまようエーテリアス의 戦闘スローモーション, アオナリ의 モーション集, SANBAN의 공격·스킬·원소폭발 목차 시리즈, 名雫代戯涙의 戦闘モーション 등이 해당합니다. 일본어 이름은 확인한 영상 링크와 함께 캐릭터 별칭으로 보관하며, `の戦闘モーション` 같은 제목도 인식합니다. 단어 내부의 유사 이름과 원소·형태가 다른 캐릭터는 구분합니다.

전체 시연 확보는 일반 공격·스킬·궁극기를 다루는 개별 시연을 기준으로 합니다. 모든 조건별 파생 동작까지 포함한다는 뜻은 아닙니다. 범위가 불분명한 스킬 시연은 부분 영상으로 표시합니다. 부분 영상이 더 넓은 시연으로 교체되면 이전 ID를 제외 목록에 남겨 반복 노출을 막습니다. 가챠 반응과 장시간 전투를 섞은 후보는 별도 무브셋 시연으로 채택하지 않습니다.

확장 채널의 일본어 유출·베타 표기도 설명까지 검사합니다. 실제 게임 녹화와 함께 게시된 정확한 `공개하지 않은 유출·테스트 서버 정보를 사용하지 않는다`는 일본어 준수 문구는 유출 영상 표기로 오인하지 않으며, 그 밖의 유출·베타 표기가 있으면 계속 제외합니다.

## 캐릭터 출시 순서

두 탭 모두 캐릭터 출시일의 오래된 순서를 기본으로 사용합니다. 출시 최신 순으로도 바꿀 수 있습니다. 영상 업로드 날짜는 정렬 기준에 사용하지 않습니다. 동시 출시는 이름순이며 같은 캐릭터 안에서는 한국어 영상이 먼저입니다. 여러 기체가 있는 퍼니싱은 기체별로 구분하고 글로벌 서비스의 출시 순서를 사용합니다. 기체를 특정하지 않는 공식 소개는 기체 공통으로 표시합니다.

공개 data/characters.json에는 출시일·별칭·출처만 저장합니다. 원신은 Remls의 캐릭터 표, 명조는 GachaTracker의 캐릭터 목록과 최신 배너 일정, 젠존제는 METAMMO의 에이전트 출시표, 이환은 NTEBUILD의 캐릭터·배너 일정, 엔드필드는 Enfieldbuild와 공식 한국어 오퍼레이터 목록, 퍼니싱은 GRAY RAVENS의 기체·패치 목록을 대조했습니다. 날짜가 미확인인 새 캐릭터는 마지막에 표시하며, 출시 정보는 별도 확인 후 갱신합니다. 영상 목록은 계속 RSS로 누적됩니다.

초기 시청 페이지 확인이 제한되면 scripts/channel_archive.py로 공개 채널 검색 목록의 영상 ID와 업로더 ID를 대조할 수 있습니다. 상대 게시 시기는 보수적인 기간으로만 기록하며 정확한 업로드 날짜를 만들어 넣지 않습니다. 캐릭터별 정렬은 별도 출시 정보에 기반합니다. 공개 목록에서 베타·유출 표기를 제외하며, 모든 영상의 내부 빌드까지 직접 판정한 것은 아닙니다.

엔드필드는 NaruVT와 ゲームシップ / Mercy의 개별 기술·전체 모션 시연으로 보완합니다. 같은 채널의 홍보용 미리보기는 제외합니다. 누락/대조 보고서는 사이트와 공개 배포물에 포함하지 않습니다.

## 그랑블루 시리즈

버서스 라이징은 Cygames EN의 Character Guide를 오피셜에, GameBurst의 Complete Moveset과 cupui의 Overview and Combo Guide를 캐릭터 무브셋 탭에 적재합니다. 해설 영상은 `해설 가이드`로 표시하며 같은 필터로 선택할 수 있습니다. 정식 출시 전 가이드는 제외합니다.

리링크는 공식 Meet the Crew와 Gaming Sora·ポテトL의 캐릭터별 공격·기술·오의 시연을 수집합니다.
